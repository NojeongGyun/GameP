[<mark>숫자 문자 차이</mark>]
  숫자는 계산을 위한 값이며, 문자는 보통 결과를 출력하기 위한 값이다.
  "123", 123 차이는 타입이 문자열이냐? 숫자냐 이다.
  a = 123; b = a * 2;  에서 a는 숫자 타입이기 때문에 b의 계산이 가능하다.
  하지만 만약 a = "123" 이라면, b는 오류가 난다. (python에서는 가능)
  print에서 물론 정수, 실수형으로 숫자를 출력 할 수 있지만 보통은 다른 문자열과 숫자 문자열을 결합하여 출력한다.
  
[<mark>꼬리 재귀</mark>]
  꼬리 재귀는 함수가 자기 자신을 호출하고, 그 호출 결과를 반환하는 것으로 작업을 끝내는 재귀 방식입니다.
  예를 들어 숫자 1~5까지 더하여 return하는 함수를 짠다고 했을 때, 반복문으로 수행하는 방법이 있는 반면, 꼬리 재귀 형식으로도 가능합니다.
  if문으로 숫자값이 0이면 total을 return하는 구문과, 재귀함수를 호출 할 때마다 숫자값이 1씩 감소되게 코드를 짜면 꼬리 재귀 형식으로 짜여 집니다.
